# CITY LIFE: UNLIMITED

A mobile-friendly, single-player 3D city driving game built with Three.js.

## Play
Open the GitHub Pages website: https://inventorbl4ze.github.io/City-life-unlimited-/

## Current version
- Third-person 3D driving camera
- Driveable original city car with rolling wheels
- Touch controls for acceleration, reverse, steering and braking
- Keyboard controls: W/A/S/D or arrow keys; Space to brake; H for horn
- Large grid city with roads, sidewalks, buildings, trees and destination signs
- Starting balance display: $50,000
- Speed display in km/h
- City map panel
- Single-player mode

## Publish
GitHub Pages should use the `main` branch and `/(root)` folder under Settings → Pages.

Three.js is loaded from jsDelivr, so an internet connection is required.

## Planned upgrades
