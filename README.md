# CITY LIFE: UNLIMITED

A single-player, mobile-friendly 3D city exploration game.

## Run
Open `index.html` with a local static server or publish the repository with GitHub Pages. Three.js is loaded from jsDelivr, so an internet connection is required.

## Publish with GitHub Pages
1. Open Settings → Pages.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then Save.
4. Wait for the Pages deployment and open the published URL.

## Current gameplay
- Third-person city exploration and touch movement controls
- 25-block city layout with labelled destinations
- Enterable location menus, furniture catalogue and purchase tracking
- Starting cash of $50,000
- Single-player local session

This is an early playable foundation. Full walk-in 3D interiors, persistent save data, NPCs, vehicles and deeper shop inventories are planned upgrades.
